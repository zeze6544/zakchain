Run your own ZAK node in one minute

22 October 2026

You need Node.js 20 or newer and nothing else.

git clone https://github.com/zeze6544/zakchain && cd zakchain
PORT=7001 node node.mjs
PORT=7002 PEERS=http://localhost:7001 node node.mjs

Make a wallet with node wallet.mjs new alice, send a transfer, then mine it with curl -X POST localhost:7001/mine. Watch the second node pick up the new block within a second.

ZAK Chain is an experimental, educational open-source project. ZAK has no monetary value, is not listed on any exchange, and nothing here is investment advice.
