Run your own ZAK node in one minute

22 October 2026

You need Node.js 20 or newer and nothing else.

git clone https://github.com/zeze6544/zakchain && cd zakchain
PORT=7001 node node.mjs
PORT=7002 PEERS=http://localhost:7001 node node.mjs

Make a wallet with node wallet.mjs new alice, send a transfer, then start the node with ALLOW_MINE=1 and mine it with curl -X POST http://127.0.0.1:7001/mine. Watch the second node pick up the new block within a second. That endpoint is off unless the flag is set, and it accepts the call only from this machine.

To see what's happening, start the explorer with node explorer/server.mjs and open http://localhost:7100. It shows every block, transfer and address, the mempool, and how the difficulty has changed.
