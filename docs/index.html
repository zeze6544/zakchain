⛓️ ZAK Chain

A complete proof-of-work blockchain in about 150 lines of plain Node.js. No dependencies. Read it, run it, break it.
View the codePlay ZAK MinerRead the launch post
Fixed supply
Exactly 1,000,000,000 ZAK in the genesis block. Nothing can mint more.
Signed transfers
Ed25519 signatures with per-wallet nonces, so transfers can't be forged or replayed.
Proof of work
SHA-256 blocks chained together. Edit an old block and every node rejects it.
Peer to peer
Nodes share transfers and blocks and agree on the longest valid chain.

Run a node

git clone https://github.com/zeze6544/zakchain && cd zakchain
PORT=7001 node node.mjs

ZAK Chain is an experimental, educational open-source project. ZAK has no monetary value, is not listed on any exchange, and nothing here is investment advice.
